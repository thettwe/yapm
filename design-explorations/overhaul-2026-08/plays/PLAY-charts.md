# PLAY — CHARTS: the viz vocabulary at journalism grade

**The idea.** Delivery stops quoting numbers and starts publishing evidence. Five named forms, each
with one rule: the ANNOTATED CYCLE TIMELINE (captions are ink on the chart — "the checkout release
went out here", "retro agreed: smaller PRs"), the DISTRIBUTION STRIP (every merged change is a dot;
"46h" becomes a drawn median you can check against the crowd behind it, with "two waited 200h+"
labeled), FLOW BAND v2 (ribbons with tinted fill, a real edge, and the count riding the ribbon;
canceled work drawn hollow — let go, not colored), REVIEW RHYTHM (small multiples, one anonymous
life per merged change, shared 0–96h scale with the tail clipped, never hidden), and the 64×18
spark grammar (TREND / CADENCE / CHECKS / SCOPE / BREAK).

**Why it is yapm's own.** Every chart keeps a plain-sentence legend (phrase dictionary intact);
git detail survives only as mono sub-lines; the rhythm grid is pattern-readable but name-free —
the team-level constraint drawn, not just promised. Annotation-as-ink is the retro/divergence
features made visible on the page where the PM already lives.

**Graduate:** the annotation grammar (bold clause + mono date + hairline leader), the distribution
strip as the canonical "typical X" treatment, ribbon counts + hollow-for-canceled, the spark
grammar, headlines-as-sentences with the urgent clause colored.
**Stay a sketch:** the timeline-as-masthead (fights the adaptive masthead's other jobs), the
hand-placed callout positions (need a collision-avoiding layout pass), and the beeswarm stacking
at real data volumes (200 PRs needs binning rules the sketch doesn't have).
