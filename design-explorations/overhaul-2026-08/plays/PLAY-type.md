# PLAY — TYPE: editorial voice as UI

**The idea.** yapm already talks like a person (the daylight phrase dictionary); this play makes
it *typeset* like one. Three inventions, pushed in `type-specimen.html` and proven in
`type-applied.html` (the Cycle Report as a designed editorial document inside the three-band
frame): (a) **divergence as pull-quote** — "The work moved, the ritual didn't." set at 56px
behind a terracotta rule, with the dictionary phrase as its red kicker and the git evidence as a
mono attribution line; (b) **the typographic metrics table** — all 12 delivery numbers as pure
type on hairlines, 46px tabular numerals, mono deltas colored by meaning (green = better,
amber = watch), zero chart ink; (c) **the number as poster** — 52/176px carrying a whole column.

**Why it is yapm's own.** Every treatment is the existing system at a different size: Figtree
650–700 with the daylight tracking ramp, IBM Plex Mono as the annotation voice (specs, shas,
datelines, captions), uppercase micro-labels as section furniture, warm tokens verbatim, and the
team-level rule set *in type* ("per-person figures don't exist here" is the table's colophon).
No serif, no elevation, no motion — the drama is scale, not decoration.

**Graduate:** the pull-quote block (digest/retro component), the metrics table as the Delivery
"dense" view, mono footnote-chips as the canonical evidence unit, and the kicker + standfirst +
black-rule dateline masthead for every generated document (cycle report, retro, digest).
**Stays a sketch:** the 176px poster numeral (report-cover energy, too loud for a 6-hour surface)
and the specimen's spec-annotation margin culture — a designer's artifact, not product UI.
